最近我发现一件挺有意思的事情：**做 GitHub 贡献好像真的会上瘾。**

一开始我以为只是图个新鲜。找个感兴趣的 Issue，看能不能修；能修就认领，拉分支、改代码、提 PR、跑 CI，然后等作者 Review。被打回来就继续改，直到最后 CI 飘绿、作者点 Approve、代码被 Merge。

可过不了多久，我又会忍不住去翻 Issues 列表：今天有没有什么新问题可以认领？有时候一天能刷好几次。

后来我琢磨了一下，为什么以前有些开源项目我毫无感觉，而这个项目却能让我停不下来？

我想不是 GitHub 本身有什么魔力，而是我碰巧撞进了一个**极高质量的工程环境**。

---

## 一个让人上瘾的工程环境

这个项目的协作机制设计得极好。Issue 永远在更新，你永远不缺下一道题。发版速度也极快，基本每天都有新版本。

这点对我尤其重要。你的代码不是 Merge 完就扔在主干里不知何时上线，而是第二天就能进发版包。你会很真切地感觉到：**我昨天写的东西，今天已经有人在用了。**

更难得的是 Review 的氛围。作者和核心贡献者几乎每天都在群里，PR 绝不会被晾着没人管。代码有瑕疵、设计不严谨，都会被毫不留情地打回来重构。

说实话，改到第三轮的时候也会头大。但奇怪的是，我心里反而挺爽。

因为这意味着：**终于有人在认真看我写的东西了。**

---

## 成为团队的“终极输出端”

这件事情反过来照出了我之前在工作里的状态。

在以前的团队里，大概 90% 的架构规范、文档和技术标准都是我来搭；核心技术方案是我定；代码最终合并前的把关，也大多卡在我这里。

久而久之，我成了整个系统最显眼的“单向输出端”。

别人遇到棘手问题来问我，方案写完递给我审，出了事故等我拿主意。这当然代表团队信任我，也证明这些年攒下的经验派上了用场。

但代价是：**我一直在输出，能得到的输入却越来越稀薄。**

不是我不学习，而是日常业务能给我的新刺激几乎见顶了。很多事情已经不是“这个我不会，我去钻研一下”，而是“这个我有经验，我来处理吧”。

做的事情越来越熟练，但“原来还可以这样写”的顿悟时刻几乎消失了。最让人心慌的是：规范是我定的，方案是我批的，如果我的判断本身有盲区，**谁来 Review 我？**

---

## Professional Loneliness

以前看到过一个词叫 **Professional Loneliness（职业孤独感）**，我觉得极其精准。

职业孤独感并不是说你身边没人。相反，过去我每天开无数个会，被拉进各种群，身边围绕着许多合作愉快的同事。

但那种感觉更像是：**我有团队，但我缺同行。**

身边能从专业角度真正挑战你、挑你毛病的人太少了。

我给出一个设计方案，很少有人能反问我：“这里为什么一定要这么做？换那种做法会不会性能更好？”我 Review 别人的代码，却很少有人能指出我实现里的破绽。

长期处于这种状态，人会有一种隐蔽的疲惫感。你依然热爱技术，也喜欢做东西，但你清楚自己的能力池一直在被抽水，却几乎没有人往里面注水。

---

## 工作在消耗，开源在充电

现在回头看，这些年真正让我觉得兴奋的输入，几乎全发生在工作之外。

自己折腾 Side Project、跟进最新的工具和技术、看别的顶尖团队怎么搞工程化，甚至包括像现在这样——把自己的代码提交给素未谋面的 Maintainer，任由对方挑刺。

表面上看，写代码好像更累了。但两者的心流完全不同：

**工作很多时候是在消耗经验，而在一个高水准的开源项目里，是在被动进化。**

在工作里，我是那个习惯说“这个我知道怎么做”的人；但在一个高质量的社区里，被严格的 CI 拦截、被 Maintainer 驳回方案时，我重新找回了说“原来这里还能这么处理”的兴奋感。

有时候我甚至很享受 PR 被打回来的过程。

因为那种被同水平、甚至更高水平的人“审视与校准”的感觉，在日常工作中已经太稀缺了。

---

## 没上班，但我找回了“同行”

这段经历，也让我坚定了短期内不再回工位上班的念头。

以前总以为要保持技术敏锐度，就必须呆在成熟体系里、带团队、扛业务。但最后发现，职场很多时候给你的不是“技术共同体”，而只是各司其职的“同事”——大家的核心诉求是需求按时上线、业务不出故障，没人有精力、也没人有兴致去深究代码写得够不够好。

离开工位之后，我反而体会到了一种很纯粹的连接。

那些在 GitHub 上给我提改进意见、甚至连续三次把我 PR 打回来的 Maintainer，我们没有任何利益往来，甚至没见过面，但他们却在专业上对我最严格、最认真。

脱节的从来不是离开工位，而是停滞在单向输出的死水里。

我不是缺工作，也不是缺同事。\
**我缺的是同行。**

原来同行本就不一定在同一个办公室里。即使暂时没有工位、没有劳动合同，至少在代码世界里，我找回了那种手艺人该有的较真与踏实。
